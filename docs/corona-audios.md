# Grabaciones de la corona solar

Guardar en `public/assets/audio/iastronaut/`. Las 11 grabaciones estan conectadas. El resumen final se reproduce despues del resultado del ultimo escaneo.

| Archivo | Texto |
|---|---|
| corona_welcome.mp3 | Bienvenido a la corona solar, aquí obtendremos registros para investigación. |
| corona_start.mp3 | Escanea las tres regiones con aro dorado. Puedes volver a los paneles para hablar conmigo. |
| corona_restart.mp3 | Operación reiniciada. Pulsa Iniciar operación para escanear de nuevo los tres registros. |
| corona_idle.mp3 | Busca las regiones con aro dorado y selecciónalas para escanear los registros pendientes. |
| corona_inner.mp3 | Corona interior registrada. Observa el halo brillante junto al borde del disco ocultado. |
| corona_filament.mp3 | Filamento coronal registrado. Observa la estructura luminosa que se extiende hacia el espacio. |
| corona_prominence.mp3 | Prominencia solar registrada. Observa la estructura rojiza que sobresale del borde. |
| corona_complete.mp3 | Investigacion completada. Registraste la corona interior, un filamento coronal y una prominencia solar. Puedes revisar los resultados o volver al Sol. |
| corona_resume.mp3 | Bienvenido de nuevo. Retoma la operación para escanear los registros pendientes. |
| corona_already_complete.mp3 | La misión de la corona está completa. Puedes consultar la ciencia o regresar al Sol. |
| corona_locked.mp3 | Completa la mision del Sol para explorar la corona solar. |
